# SmartMove MongoDB content

These scripts provide the optional MongoDB coursework component. The current React application uses local demo data and does **not** connect to a live MongoDB server.

Run `collections.js`, then `sample_data.js`, in `mongosh` against a database such as `smartmove_demo`. Use `queries.js` for route reviews, rating summaries, complaint keyword searches, vehicle documents, trip media, and active announcements.

The four collections are `vehicle_documents`, `passenger_reviews`, `travel_announcements`, and `trip_media`. Replace demo URLs and sample records before production use.
