# Viva questions

1. Why use Oracle for transactional data? It provides constraints, joins, sequences, views, and PL/SQL.
2. Why use MongoDB? Flexible reviews, announcements, documents, and media content fit document storage.
3. How is a booking linked to a trip? `bookings.trip_id` references `trips.trip_id`.
4. How are reports produced? The UI demonstrates local calculations and `plsql/reports.sql` provides Oracle queries.
5. Is the current browser connected to a database? No; it clearly uses demo data.
